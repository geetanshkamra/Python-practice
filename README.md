# 🐍 Python Practice

My Python learning journey: string methods and practice problem solutions, all in Jupyter notebooks.

## 📚 Contents

| Notebook | What's inside |
|---|---|
| [strings_methods.ipynb](strings_methods.ipynb) | Python string methods explained with examples and output |
| [string_practice.ipynb](string_practice.ipynb) | String-based practice problems with solutions |
| [python_50_solution.ipynb](python_50_solution.ipynb) | 52 practice problems solved using classes, functions and exception handling |

## 🧠 Topics Covered

- **Strings:** methods, reverse, palindrome, vowels, anagram, character frequency
- **Lists:** largest and second largest, remove duplicates, flatten, merge, binary search, subsets
- **Numbers:** prime, factorial, GCD and LCM, Armstrong, Fibonacci, leap year
- **Recursion:** factorial, GCD, sum of a list
- **Data structures:** stack and queue using lists
- **File handling:** word frequency from a text file

## ▶️ How to Run

```bash
git clone https://github.com/geetanshkamra/Python-practice.git
cd Python-practice
pip install notebook
jupyter notebook
```

Then open any `.ipynb` file from the Jupyter window.
